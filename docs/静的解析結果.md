## 対応が必要な項目

### 1. ESLint依存関係のHigh脆弱性

- **検出結果:** `npm audit` がHigh 5件を報告。`eslint-config-next@16.4.2` から `@next/eslint-plugin-next`、`fast-glob`、`micromatch`、`braces` へ続く開発依存関係です。
- **主な勧告:** [GHSA-vfj7-8cjw-p6xm](https://github.com/advisories/GHSA-vfj7-8cjw-p6xm)（`braces` の深くネストしたパターンによるスタック枯渇DoS）。
- **対応:** Next.js 16と互換性のある修正版のESLint依存関係が利用できるか確認し、互換性を保った更新を行う。現時点で `npm audit fix` が提示する `eslint-config-next@14.2.35` への変更はメジャーダウングレードのため適用しない。

### 2. Jestの依存関係に残るModerate脆弱性

- **検出結果:** `npm audit` がModerate 20件を報告。`jest@30.5.2` と `ts-jest@29.4.15` から、`babel-plugin-istanbul`、`@istanbuljs/load-nyc-config`、`js-yaml`、`argparse`、`sprintf-js` などへ続く開発依存関係です。
- **主な勧告:** [GHSA-hp3w-g68c-fv3c](https://github.com/advisories/GHSA-hp3w-g68c-fv3c)（`sprintf-js` の精度指定に上限がない場合のDoS）。
- **対応:** Jestの現行メジャーと互換性のある修正版または代替のテスト・カバレッジ構成を確認する。`npm audit fix` が提示する `ts-jest@27.0.3` や `jest@25.0.0` への変更はメジャーダウングレードのため適用しない。
