# 収入可視化アプリ 要件定義書

## 目的

年ごとの収入とその内訳を、グラフで直感的に比較できるアプリを作成する。

## 決定済み要件

| ID | 要件 |
| --- | --- |
| FR-001 | 収入を可視化するアプリとする。 |
| FR-002 | 収入の内訳を積み上げ棒グラフで表示する。 |
| FR-003 | 横軸は西暦（年）とする。 |
| FR-004 | 縦軸の金額単位は万円とする。 |
| FR-005 | 給与収入、配当金、その他の収入を積み上げて表示する。 |
| FR-006 | リポジトリ内のCSVファイルからサンプルデータを読み込み、グラフに表示する。 |
| FR-007 | サンプルCSVは `data/income.csv` に配置し、1年につき1行で `year,salary,dividends,other` の列を持つ。 |
| FR-008 | CSV内の収入額は円単位の整数で記録し、表示時に万円へ換算する。 |
